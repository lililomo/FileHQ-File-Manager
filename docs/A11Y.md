## 4. Tema gelap

- `grep -E "#[0-9a-fA-F]{6}" web/src` di luar `styles/tokens.css` = **0** (pengecualian yang diizinkan PROMPT: `tokens.css`, palet Monarch editor, palet treemap — keduanya kini tidak memuat hex). `--color-destructive-foreground` kini token `--danger-fg`.
- Warna di luar token yang tersisa dari review B m-07 dipindah ke token: titik tag `--tag-*` dan bintang favorit `--star`/`--star-fill` (terang + gelap), ghost drag `var(--accent-fg)`; tombol/badge destruktif `text-destructive-foreground`.
- Pengecualian palet Tailwind netral yang disengaja (bukan hex, tidak bergantung tema): permukaan media — latar pemutar video/Quick Look `bg-black` + kontrol `white/…`, kanvas halaman PDF dan thumbnail PDF `bg-white` (kertas), QR code `bg-white` (kontras pemindaian), overlay modal `bg-black/50`.
- Ikon tipe file memakai token `--icon-*` (terlihat di terang dan gelap; sprite SVG `currentColor`); thumbnail berupa gambar asli dengan border token.
- `prefers-reduced-motion`: token durasi 0 ms + aturan global animasi/transisi 0,01 ms (`globals.css`), cincin undo statis.

## 5. Pengecualian & sisa yang diketahui

- Context menu ponsel muncul di titik sentuh (Radix ContextMenu), bukan "Sheet bawah" seperti tulisan SPEC §9.9 — fungsi dan target sentuh sama; lihat Deviasi di PROGRESS.
- Ketuk satu kali di ponsel menyeleksi (bottom bar muncul), membuka = ketuk dua kali atau "Buka" di menu/⋯; SPEC "mode seleksi (tap checkbox)" dipenuhi oleh ketuk baris.
- View Grid/List/Tiles memakai pola keyboard yang sama dengan Details (diuji di `views.spec.ts` Step 8) tetapi axe hanya dijalankan pada Details + Large icons.
- Monaco: aksesibilitas mengikuti mode pembaca layar bawaan Monaco (Alt+F1 / Ctrl+E); tidak diaudit lebih jauh.
- `<select>`/`<input type=date>` native di beberapa filter admin (review E m-18) dipertahankan: native justru paling aksesibel; hanya gaya yang berbeda.
