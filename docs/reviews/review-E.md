## 1. Ringkasan

Lapisan otorisasi **menahan semua probe IDOR dan escape subtree**: setiap `/api/v1/admin/*` yang terdaftar di router chi (25 route, dibaca secara programatik lewat `chi.Walk`) menjawab `403 FORBIDDEN` untuk user biasa dan `401` tanpa sesi, id acak/milik user lain di share, recipients, access-logs, sessions, admin users/tasks/shares/backup menjawab `404`; `?share=` dengan path absolut/`..`/symlink keluar folder, id share publik, id acak, `share`+`as_user`, share kedaluwarsa/dinonaktifkan pemilik/dicabut admin/pemilik nonaktif/penerima nonaktif semuanya ditolak dengan kode yang benar (termasuk signed URL `r:` yang diperiksa ulang tiap pemakaian); file tunggal tidak pernah membuka induk atau sibling; editor tidak bisa chmod/symlink/compress/extract/batch-rename/undo lewat scope (400 `not_supported`) dan penghapusannya masuk Recycle Bin pemilik; upload file request tidak bisa menimpa maupun keluar folder (`../`, `a/b`, NUL, `relativePath` naik); password sementara admin tidak pernah muncul di log server, tabel audit, maupun notifikasi; logo hanya PNG (SVG dengan `Content-Type: image/png` → 415, poliglot PNG+SVG dilayani `image/png` + `nosniff` + CSP `sandbox`); export CSV menetralkan `= + - @ TAB CR` di semua kolom; reset password admin dan logout-all mematikan sesi target; nilai ekstrem settings (overflow durasi, `1e30`, `NaN`, `tz_default` traversal, relasi chunk/upload, idle/absolut) ditolak `400` dengan `details.key`; fuzz 4 target (path tamu, token/slug, grammar slug, cookie unlock) tanpa crash/5xx/kebocoran.

Ditemukan **0 blocker, 3 major, 21 minor** (15 kode + 6 UX). Major: (M-01) `max_downloads` **bisa dilewati** lewat `Range: bytes=1-`/`bytes=-N` setelah batas tercapai (kelanjutan Range sengaja tidak dihitung, tetapi tidak diperiksa terhadap batas); (M-02) **token dan slug link publik tercatat di access log** aplikasi (`path` penuh `/s/<token>` dan `/api/v1/public/shares/<token>/…`) — kredensial bearer di journald; (M-03) **path absolut pemilik bocor ke tamu dan penerima** lewat tiga jalur upload: `upload/precheck` publik (`items[].path = /dok-rahasia/drop/a.txt`), echo `Upload-Metadata path=` pada `HEAD` tus, dan header `Upload-Path` pada PATCH terakhir — melanggar AC 18b "tidak ada path absolut pemilik di respons penerima" dan `hide_owner` untuk struktur folder di atas share.

Baseline verifikasi (sebelum perbaikan): `make build` OK; Go `-race -cover` 27 paket OK; Vitest 228/228; JS awal **223,8 KB gzip** (jumlah gzip 19 file JS yang dirujuk `index.html`; 19b melaporkan 218,4 KB dengan metode lain).
