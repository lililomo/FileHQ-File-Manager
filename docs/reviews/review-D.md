## 1. Ringkasan

Lapisan search/editor/viewer **menahan hampir semua probe** yang dicoba: nama file berisi `<img src=x onerror=…>` / `<svg onload=…>` tampil sebagai teks di **semua** permukaan (grid, breadcrumb, header viewer, panel info, Quick Look, tab editor modal dan route, toast rename, baris task, notifikasi, baris panel transfer, hasil pencarian nama & isi), Markdown/JSON tree/CSV merender payload sebagai teks, SVG hanya lewat raster `variant=preview`, HTML selalu sumber; 12 varian encoding/EOL (UTF-8 ± BOM, UTF-16 LE/BE, GBK, Big5, Shift_JIS, EUC-KR, windows-1252, ISO-8859-2 via override, KOI8-R, EOL campuran, CR saja) **round-trip byte-identik** (`noop:true`); `If-Match` yang hilang ditolak `409`; versi terisolasi per user (list/content/download/restore/delete/delete-all user lain → 404 atau tidak menyentuh); replace atomik dengan pre-image, melewati biner dan file yang diganti symlink/berubah setelah pratinjau, mode dipertahankan, tanpa sisa staging; argumen ripgrep tidak bisa menjadi flag (`-e`, `--`, `--no-follow`, `--no-config`); signed URL `media` tidak diterima di `download`/`zip`/`thumb`/`entry-content` maupun setelah `purpose` ditulis ulang; sanitizer subtitle dan parser EXIF lolos fuzz 30 s masing-masing (356.804 / 535.404 / 537.215 eksekusi) dengan invarian; konsol bersih (CSP/worker) di editor, PDF, dan video; Tab tidak pernah keluar dari overlay; input pencarian PDF memiliki `r i 0 f 1`; JS awal **203,2 KB gzip**, Monaco/pdf.js/Video.js/highlight.js semuanya chunk lazy.

Ditemukan **0 blocker, 2 major, 16 minor** (10 dari kode, 6 dari UX pass). Major: (M-01) deteksi password arsip **7z tidak deterministik dan salah untuk anggota pertama kosong** — bodgit menurunkan kunci AES dari password kosong, probe lama membaca satu byte dan menganggap "tidak error" sebagai "tidak terenkripsi" (pasti terjadi bila anggota pertama kosong, ±1/256 untuk LZMA karena byte pertama sampah harus nol — inilah akar `TestSevenZipPasswordNeverInArgv` yang flaky), sehingga ekstraksi tanpa password dilaporkan `ARCHIVE_CORRUPT` alih-alih `PASSWORD_REQUIRED` dan browser arsip tidak mendapat `session`; sekaligus ditemukan bahwa anggota 7z **tidak pernah diverifikasi CRC** sehingga password salah pada folder `Copy`+AES (atau data rusak) diekstrak diam-diam sebagai sampah; (M-02) sesi tab editor **memulihkan tab untuk file yang sudah tidak ada** sebagai tab error permanen yang ikut disimpan ulang (checklist f: "tab dipulihkan hanya untuk file yang masih ada").
